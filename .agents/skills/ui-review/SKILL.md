# ui-review

Inspect current UI and design tokens before suggesting changes. Check visual hierarchy, contrast, touch targets, focus states, labels, keyboard, safe areas, scrolling and loading/error states. Preserve existing brand; don't add invented design packages or enforce a new visual language. Implement only requested changes and run relevant frontend checks. This skill is independent of snowe-ui-skill.
