# symfony-feature

Read `backend/AGENTS.md` and relevant PHP rules. Inspect installed Symfony/PHP versions, service wiring and endpoint conventions. Identify DTOs/contracts in `include/`, reusable integration in `lib/`, and runtime in `src/` if using the three-root architecture. Keep controllers thin. Don't invent bundle APIs or missing contracts. Add focused tests and execute configured validation. Review any migration separately.
