# doctrine-migration

Inspect entities, Doctrine config, existing migrations and database platform. Change mappings intentionally. Generate a migration only using project tooling; review up/down SQL for data loss, locking and reversibility. Do not apply to production or unfamiliar databases by default. Test schema/migration changes in a safe environment if available. Report SQL risks and checks.
